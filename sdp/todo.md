# Solana Todo
## 数据上链
### 活动数据上链
+ 仅针对发布的活动，即主办方点击发布时，数据才上链(好处是发布前一般需要频繁修改活动信息，此时不上链可以节省gas)
### 签到数据上链
+ 无特殊需求，简单校验账号信息，并且颁发NFT即可
### 投票数据上链
+ 当投票截止时间结束后，数据统一上链，即过程中的投票和撤销投票数据不用反复上链

## 金额
### 赞助商相关
+ 所有赞助商发起申请后，需要设定一个默认的审核时间，审核通过，则将金额转入主办方钱包；审核失败，金额原路返回
### 活动相关
+ 首先先建一个金库，将比赛金额加到这个金库中，其中包括主办方钱包+指定赞助商钱包中的钱
+ 当比赛结束后，金库中的钱按照投票结果直接分发，剩余的钱按照比例返回给主办方+指定赞助商
### 需要注意的项
+ 当一个活动后，第一件事，就是创建金库
+ 之后所有数据上链所需的费用，都是从这个金库里扣除的（包括活动数据上链、签到数据上链、颁发NFT、投票数据和所有的gas费用）
+ 签到这个环节很重要，假定签到了100个人，之后投票、分发奖金的地址只能从签到的地址列表中获取，并且获取数据是走链上，而非线上
+ 这里再详细说明一下，即投票、分发奖金时，需要读取链上的签到列表，以此来保证数据不可篡改，至少是签到的人的钱包
+ 分发奖金的逻辑：当活动创建后，分发逻辑其实已经固定，只是从投票的链上数据中，分析得出名次，后续再按照已经固定的顺序，自动分发奖金即可
