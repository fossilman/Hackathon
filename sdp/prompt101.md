## PART1

### web3 功能使用 Solana 链,使用本地测试链

### 发布的活动功能新增
+ 创建 活动发布 web3的program
+ 活动点击发布后，将数据同步至program中

### 签到活动功能新增
+ 创建 签到活动 web3的program
+ 点击签到,将数据同步至program中，并生成用户对应的NFT
+ 假定签到了100个人，之后投票、分发奖金的地址只能从签到的地址列表中获取，并且获取数据是走链上，而非线上

### 投票功能新增
+ 创建 投票 web3的program
+ 用户投票,将数据同步至program中

### 赞助商功能新增
+ 赞助商发起申请后, 设定一个默认的审核时间, 审核通过将金额转入主办方钱包; 审核失败金额原路返回

### 活动整体流程
+ 活动发布后，同时创建一个金库，将比赛金额加到这个金库中，其中包括主办方钱包+指定赞助商钱包中的钱
+ 活动过程中，所有的 活动数据上链、签到数据上链、颁发NFT、投票数据和所有的gas费用 都从这个金库中扣除
+ 活动完成后，金库中的钱按照投票结果直接分发，剩余的钱按照比例返回给主办方+指定赞助商
    + 分发奖金的逻辑
        + 当活动创建后，分发逻辑其实已经固定，只是从投票的链上数据中，分析得出名次，后续再按照已经固定的顺序，自动分发奖金即可

### Tip
+ 投票、分发奖金时，需要读取链上的签到列表，以此来保证数据不可篡改，至少是签到的人的钱包
